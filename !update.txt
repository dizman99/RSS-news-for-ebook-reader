07.09.2026
- found out, the programm did not work fine with malicious RSS Links.
  It then hangs in the writing of the JSON file. This is now fixed, there is a Timeout now of 10 seconds, before
  the thread (rss-feed) is treated as corrupted. Those will be just left out on creating the resulting epub on it,
  so everything is fine now.
- found out, that it is possible to sync with an empty master directory.
  This might even be wished for, if you want to create all from scratch. Nevertheless it syncs that
  empty directory to your reader then, which thereafter is empty to. In case this just happens accidentally, the 
  program now checks this occasion and comes up with a warning dialog and which consequences it has if you preceed.
  You then can still continue with this operation or just break it up back to the dialog level. No harm is done then.
